# FISSION简介 
>一款基于教程项目修改重置的小游戏 (下方有游玩示例)

>游戏名称灵感只是因为游戏中的'石头'击碎后会像核反应一样分裂/fission ~~(笑)~~

>有一定的 *Roguelike* 属性, 和 *魂游(?)* 机制

  `感谢 liangxiegame 的项目教程与 啓樺() 参与全程的游玩测试`

## 玩法流程

#### 鼠标操控属于你的 **'小飞机'**  
>不过要注意, 你没有任何失误空间, **'小飞机'** 不能受到任何形式的碰撞 (屏幕边缘不算, 当碰到右侧边缘时会从左侧飞出)

#### 通过击碎四面八方袭来的 **'普通石头'** 或 **'特殊石头'** 以获取 **分数(弹药)** 以及 **升级**
>(鼠标位置控制朝向, 右键长按移动, 左键消耗分数射击, 中键使用不消耗分数的近战攻击) 

#### 在 **3分钟** 倒计时结束后, **'BOSS'** 就会登场  
>单局游戏内会有两场BOSS战, 在战斗前充分做好准备, 它们可不好对付

#### 战胜两名 **'BOSS'** , 获得游戏胜利
>以及合理利用道具, 刷新你的最高分


## 游戏内容
  当前游戏内容有  
- **5项升级**
  - **攻击伤害 (紫色)**   - 每级提升 **1点**  攻击(射击/近战)的伤害与射击的花费
  - **攻击速度 (绿色)**   - 每级提升 **12%** 攻击速度(基于提升后的数值计算)
  - **弹道数量 (朱红色)** - 每级增加  **1个** 攻击时发射的子弹或近战的剑气(会略微提升攻击的扩散)
  - **弹道优化 (亮黄色)** - 每级提升  **20%** 子弹飞行速度/剑气长度, 并减少弹道数量增加带来的扩散
  - **机动性 (深蓝色)**   - 每级增加 **25%** 的加速度与  **20%** 的阻力(更快停止移动, 而不是漂移)

   ---
  
- **9项道具**
  - **无敌 (浅蓝色+同色粒子)** - 持续 **10秒**
    - `期间无视任何形式的伤害, 可撞碎'普通石头'`
  - **膨胀 (红色+扩散方框)** - 持续 **10秒**
    - `期间攻击的子弹大小放大10倍, 剑气放大3倍`
  - **隧穿 (深蓝色+同色粒子)** - 持续 **10秒**
    - `期间发射的子弹将与角色一样可在屏幕中连续穿行`
  - **混乱 (青绿色+乱飘粒子)** - 持续 **10秒**
    - `期间发射的子弹将朝随机方向旋转`
  - **龙卷 (青绿色+环绕粒子)** - 持续 **3秒**
    - `期间发射的子弹将统一向'小飞机'左侧旋转`
  - **莲华 (粉红色+六芒星闪烁)** - 持续 **3秒**
    - `期间的单次攻击将变为以自身为圆心向360度连续进行12次无消耗攻击(基于当前弹道数量)`
  - **弹射 (紫色+同色闪烁)** - 持续 **20秒**
    - `当击碎'普通石头'子弹还存在的话, 则向随机角度弹射`
  - **狂潮 (金色+橙色粒子)** - 持续 **5秒**
    - `期间'普通石头'的分数价值翻50倍`
  - **涅槃 (青色+圆形光辉)** - **永久(可按层数叠加)**
    - `显示在升级栏位, 每层可抵消一次致命失误, 然后提供3秒无敌并摧毁一定范围内的所有'普通石头'`
   
  ---
  
- **2只完整BOSS**
  - ***test (测试)***
      - 基础拥有3个技能: **冲撞 / 跟踪 / 发射普通石头**
      - 二阶段 **(50%生命)** 额外追加2个技能: **辐射 / 四角冲刺** 并大幅度减小技能前后摇并增加技能强度
  - ***emissary (使者)***
    - 基础拥有4个技能: **八向激光 / 旋转激光 / 万向 / 轮锯**
    - 二阶段 **(66%生命)** 大幅度减小技能前后摇并增加技能强度
    - 三阶段 **(33%生命)** 进入第二形态: **使者** , 技能替换为: **四角激光 / 长距冲刺 / 冲击与射击 / 清理**

  ---

- **14级可选难度** (1级为初始等级, 最低-3 最高10级)
  - 每级 **减少/增加** 游戏危险源 **'石头' / 'BOSS'** 的移动/旋转速度;
  - 每级 **减少/增加** 游戏难度曲线发展速率;
  - 每级使 **'特殊石头'** 的生成效率额外增加 **基础效率 * 当前难度绝对值** ;
  - 1级以上每级 **减少 'BOSS'** 技能前后摇;
  - 1级以上每级 **增加 'BOSS'** 技能强度;
  
    `当前难度系统作为游戏挑战性的直接系数, 选择合适自己的可更好体验完整的游戏流程`
